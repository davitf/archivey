## Checkpoint read (mid-pass clusters)

Divergences cluster in three places:

1. **Error-boundary / silent knobs** — volumes `ValueError`, `encoding=` discard,
   ZIP closed misclassification (F1–F3).
2. **Residual Path capability gate** — single-file `compressed_size` (F6); other
   Path sites are open/materialize.
3. **Documented format law** — pipe matrix, TAR streaming final-header, header
   encryption eagerness, encryption wrong-password shapes. These should stay
   queryable / Gotchas-true, not "fixed" into a lie.
