# Claude Code — Archivey

**Read [`AGENTS.md`](AGENTS.md) first**, starting with its "Every task" block. It is the
canonical agent guide; this file holds only what is specific to Claude Code.

- **Session setup runs automatically** via the `SessionStart` hook
  (`.claude/hooks/session-start.sh`), which calls `scripts/setup-dev-env.sh` and no-ops
  unless `CLAUDE_CODE_REMOTE=true`. Read its closing verification block; if you did not
  see it, run the script by hand.
- **A fresh container has no memory of earlier sessions.** Before re-deriving something
  that feels settled, check `dev-docs/code-map.md` §"Where the answers live".
- **Ask for the review skills by name:** `/code-review-skill` produces findings,
  `/address-review-findings` dispositions them. A bare `/code-review` is a builtin skill,
  not this repo's. The autopilot entry point is a **path, not a slash command**: when you
  react to PR events rather than a request, read `.claude/skills/steward/SKILL.md` first.
- **Footer:** end every comment and review you post with
  `_Generated by [Claude Code](https://claude.ai/code)_`, written yourself.
